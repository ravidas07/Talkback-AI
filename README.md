# 🔊 TalkBack AI – Voice Chat Assistant with GUI

**TalkBack AI** is an interactive voice-based assistant built with Python. It uses a natural-language model (via OpenRouter), real-time transcription (`faster-whisper`), and a beautiful `Tkinter` GUI to create a seamless talking experience.

> 🧠 Speak. Transcribe. Think. Talk back.

---

## ✨ Features

- 🎙️ **Voice input** using real-time audio recording
- 🧠 **Transcription** with `faster-whisper` for fast and lightweight speech-to-text
- 🤖 **AI-powered replies** via OpenRouter LLMs (e.g. Mistral)
- 🗣️ **Text-to-speech (TTS)** voice output with `pyttsx3`
- 💬 **Chat history** maintained in conversational context
- 🎛️ **Modern GUI** with smooth loading animations
- 🔁 **Auto-reloading GUI** using `watchdog`
- ✅ Runs in a custom Conda environment

## 🧑‍💻 Tech Stack

- Python 3.10
- `Tkinter` – GUI framework
- `faster-whisper` – Speech-to-text
- `pyttsx3` – Text-to-speech
- `OpenRouter` – LLM API interface
- `pyaudio` – Microphone input
- `dotenv` – Environment variable handling
- `watchdog` – Hot-reloading on file change
